## 功能详细介绍

### 📖 学习功能

#### 分 Tab 互动课件
学员点击"开始学习"后，课件以弹窗形式打开，顶部是紫色导航条（"← 返回课程列表" + 学员姓名），下方是题型页签。

- **📚 课程导读**：课程视频（mp4 直链内嵌播放；微信云盘等分享链接显示"观看课程视频"卡片，新标签页打开）、课程导览卡片（数字徽章 1/2/3 + 章节标题 + 要点列表）、答题说明（管理端可自定义，留空则自动生成如"本课共一、经文诵读2题、二、填空题6题……"）、"开始答题 →"按钮
- **按题型分页**：页签按课程实际含有的题型动态生成，顺序固定为经文诵读 → 填空题 → 单项选择题 → 多项选择题 → 判断题 → 问答与思辨；每个页签显示题数（如"填空题 6题"）
- **📊 成绩报告**：答题完成后显示客观题得分、理解掌握评级（融会贯通/掌握良好/需再复习/继续加油）、复习提示；可"返回修改填写"或"重新作答"
- **自适应模式**：有章节的课程自动渲染为课件模式——题目按章节分组（蓝色数字徽章 + 章节名），顶部实时显示"已填写 X / 总数"进度，填完才可核对；无章节的课程渲染为平板测验
- **底部切换**：每个题型区域底部有"← 上一题型：XX / 下一题型：XX →"按钮（最后一个题型为"查看成绩报告 →"），拉到底部可直接切换题型并自动回到顶部，不用再拉回顶部点页签
- **即时反馈**：点击"核对答案"后，每道题内联显示 ✓/✗，选择题选项红绿反馈，问答题可展开参考答案；底部常驻核对条显示填写进度

#### 六种题型
| 题型 | 说明 |
|---|---|
| 经文诵读 📖 | 经文填空，蓝色卡片呈现；引用显示三徽章（📜金色图标+书名紫色如"马太福音"+章节蓝色如"第28章19节"，简称自动补全称），经文正文琥珀底纹高亮；题干"【经文填空】"字样自动去掉（课件、错题本、导出统一） |
| 填空题 ✏️ | 题干内嵌输入框，下划线越长输入框越宽；支持多答案判分——`|` 分隔各空，`/` 分隔同空多答案（如答案写"失败/软弱"，答任一均正确） |
| 单项选择题 🔘 | 四选一，点击选项即选中 |
| 多项选择题 ☑️ | 复选框多选，判分与选择顺序无关，核对后标出全部正确选项；题干末尾自带的"（多选）"字样自动去掉，只保留紫色"（多选）"徽章 |
| 判断题 ⚖️ | √ / × 二选一 |
| 问答与思辨 💬 | 大文本框作答，核对后展开参考答案对照 |

#### 经文高亮
系统内置 66 卷书名白名单（含常用简称），自动识别课件中提到的具体经文，引用统一显示为"全称第N章M节"：
- **📜 图标**：金色渐变徽章（独立）
- **书名**（如"马太福音"）：紫色渐变徽章；简称自动补全称（太28:19→马太福音第28章19节）
- **章节**（如"第28章19节"）：浅蓝底蓝边框徽章；冒号格式自动转换（约3:16→第3章16节），跨节范围支持（弗2:8-9→第2章8-9节）
- **经文正文**：显示为琥珀色底纹 + 下划线高亮
- 覆盖范围：首页公告栏、课程卡片标题/简介、系列介绍、课程介绍、经文题卡片、填空/选择/问答题干、课程导读要点、以及网页/Word/Excel/PPT 全部导出格式（PPT 用多 run 分段着色：图标金色、书名紫色加粗、章节蓝色、正文深琥珀色）

#### 错题本 📝
- 核对答案后，答错的题目自动收录，每条记录带：系列、子栏目、课件名、题型、题号（如"填空题 · 第3题"）、学员答案、正确答案
- 按学员姓名隔离存储，换姓名看不到别人的错题
- 入口有两个：主页顶部"错题本"按钮看该姓名下全部错题；每个课件顶部标题栏右上角 📝 只看本课件错题（标题显示课件名，导出/清空也只作用于本课件）
- 错题本弹窗有 📥 导出按钮，格式与课件导出完全一致（网页/Word/Excel/PPT 单页版/PPT 两页版/打印），文件名如"张三的错题本.doc"

#### 学习进度与成绩
- 课程卡片左上角徽章：○ 未开始 / ◐ 进行中（橙色）/ ● 已完成（绿色）
- 首页顶部统计卡：全部课程数、已完成数、进行中数、平均分
- 进度按姓名隔离存储：未登录时全部显示"未开始"；登录后只看自己的；登出后徽章统计回到初始态
- 点击"核对答案"后成绩自动上传服务端（时间戳去重，重复核对不产生多条）；学员可在首页按姓名查自己成绩

### 👤 学员系统

#### 姓名 + 密码登录
- 首次使用点任何答题页签（或"开始答题"）时弹出登录框：输入姓名 + 设置密码（4 位起）即注册，老学员直接登录
- 密码 SHA-256 加用户名盐哈希存储；登录态为 token，存在本地
- 顶部按钮显示当前学员姓名，点击可登出（二次确认）；登出只清登录态，该姓名下的错题本与本地答题记录保留
- 分享页（课程短链打开）也有姓名门禁，逻辑与主页一致
- 忘记密码：登录框下方有"忘记密码？请联系老师重置"提示，老师在管理端学员列表点"重置密码"即可帮学员设置新密码
- 登录成功后显示全屏欢迎动画："欢迎［学员名字］开启学习之旅！"，约 3 秒自动消失，点击可关闭

#### 防冒名
- 已注册的姓名提交成绩时必须携带有效 token，否则服务端拒绝；未注册过的姓名保持兼容（可直接答题，成绩记名下）

#### 学员管理员 👑
- 管理端"学员管理员"区块可查看所有注册学员，一键设置/取消管理员
- 被设为管理员的学员（打开课件时自动刷新身份，无需重新登录）：课件顶部右侧显示「🔑 教师版查看答案」按钮（替代错题本位置），点击直接内联显示所有答案，无需答题；课程导读页也有「📖 查看全套参考答案」
- 服务端鉴权：/api/answers 接受学员管理员的 username+token

## 技术栈

- **Cloudflare Workers**（单文件 `worker.js`，约 3700 行）
- **Cloudflare D1**（SQLite）——表：`courses`（课程）、`categories`（栏目）、`scores`（成绩）、`settings`（设置/公告/密码）、`students`（学员）、`wrongs`（错题）
- 前端：原生 HTML / CSS / JavaScript（Tailwind CDN），无构建步骤
- 管理登录：HttpOnly Cookie + SHA-256 密码哈希；学员密码 SHA-256 加盐哈希
- 服务端判分；未登录时 API 不下发答案；HTML 带 `Cache-Control: no-store` 防缓存
- 加载优化：首页只下发课程精简字段（题库/导读按需加载），公开接口边缘缓存 60 秒，首屏请求并行化

### 数据模型（`courses` 表）

| 字段 | 说明 |
|---|---|
| id / category / subcategory / title | 课程 ID、系列、子栏目、标题 |
| content | 课程导读（Markdown） |
| quizzes_json | 题目数组 `[{type, s, q, o, a}]`，type ∈ single / multiple / fill / judge / essay / verse |

## 题目 JSON 格式

```json
[
  { "type": "single", "s": "第一章", "q": "题干", "o": "A.选项一, B.选项二", "a": "A" },
  { "type": "fill", "s": "", "q": "罪使人与上帝的______隔绝。", "o": "", "a": "生命" },
  { "type": "judge", "s": "", "q": "判断题干", "o": "", "a": "√" },
  { "type": "essay", "s": "", "q": "问答题干", "o": "", "a": "参考答案" }
]
```

- `type`：single（单选）/ multiple（多选，答案用 `|` 分隔如 `A|C`）/ fill（填空）/ judge（判断，答案 `√`/`×`）/ essay（问答）/ verse（经文）
- `s`：章节名（可空，用于课件内按章节分组）
- `o`：选项（选择题逗号分隔）/ 经文出处（经文题如"《罗马书》1章20节"）
